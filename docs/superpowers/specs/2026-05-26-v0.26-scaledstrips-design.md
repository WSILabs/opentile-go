# opentile-go v0.26 — ScaledStrips Iterator

**Status:** Design approved 2026-05-26.

## 1. Goal

Add a high-throughput strip iterator to `*Slide` that scales a slide
to a target output resolution and yields horizontal strips of decoded
pixels. Internally uses parallel decode + tile cache + lookahead
pre-fetch — the libvips-comparable-speed primitive that dzsave /
tile-server / region-extract tools consume.

After v0.26, callers writing dzsave-class pipelines stop having to
implement the worker-pool + cache + lookahead dance themselves —
opentile-go owns it. The naive "loop ReadRegion" pattern still works
for ad-hoc reads; ScaledStrips is the opt-in fast path.

## 2. Scope

In scope for v0.26:

- New `*Slide.ScaledStrips(l0Rect, outSize, stripHeight, opts...)`
  method returning a `*StripIterator`.
- `*StripIterator` with `Next()`, `Close()`, and `Strips()` methods.
- Five `StripOption` helpers:
  - `WithStripWorkers(n int)`
  - `WithStripLookahead(strips int)`
  - `WithStripIDCTScale(scale int)` (override; default auto)
  - `WithStripKernel(k resample.Kernel)`
  - `WithStripContext(ctx context.Context)`
- Auto-select logic for source pyramid level (via
  `BestLevelForDownsample`) and IDCT scale factor (JPEG sources).
- Internal per-iterator tile cache (bounded by tile count, LRU
  eviction).
- Internal parallel decode workers with lookahead pre-fetch.
- Out-of-bounds + missing-codec error handling matching
  `ReadRegion` semantics.

Out of scope (deferred to later):

- Public `*Cache` type for cross-iterator sharing. v0.27+ if a
  real consumer (tile-server) materializes.
- Multi-image variant `ImageScaledStrips(image, ...)`. Future
  release when multi-image OME-TIFF surface stabilizes.
- Vertical-axis strips (column iteration). Future option.
- Async / channel-yielding API. Caller can wrap `Next()` in a
  goroutine + buffered channel if they want overlap.
- Benchmarks comparing against libvips dzsave. Defer to a
  follow-up after the first working implementation is shipped.
- Go 1.23 range-over-function adapter (`*StripIterator.Range()`).
  Trivial to add later if range syntax becomes preferred.

Non-goals:

- Backwards compatibility shims. Purely additive over v0.25.
- Changes to existing decoder / resample packages or format
  readers.
- Output format changes (still emits `*decoder.Image`).

## 4. Public API

### 4.1 Method signature

```go
package opentile

import (
    "image"

    "github.com/wsilabs/opentile-go/decoder"
)

// ScaledStrips returns an iterator over a slide's L0 rectangle,
// scaled to outSize, in horizontal strips of stripHeight rows.
// Reads use parallel decode + tile cache + lookahead pre-fetch —
// the iterator is the right primitive for dzsave-class throughput.
//
//	l0Rect    — L0 source region. For the whole slide, pass
//	            image.Rect(0, 0, L0Width, L0Height). Out-of-bounds
//	            areas are auto-clipped and white-filled.
//	outSize   — total output dimensions (outW × outH). Choose any
//	            value regardless of pyramid level resolutions.
//	stripHeight — rows per yielded strip. The library iterates
//	            ceil(outSize.Y / stripHeight) strips. Each strip
//	            (except possibly the last) is outSize.X × stripHeight;
//	            the last strip may be shorter.
//	opts      — see StripOption (workers, lookahead, kernel, etc.)
//
// Each call to *StripIterator.Next() returns one strip. Caller
// must Close the iterator. Common pattern:
//
//	it := slide.ScaledStrips(l0Rect, outSize, stripH)
//	defer it.Close()
//	for {
//	    img, err := it.Next()
//	    if err == io.EOF { break }
//	    if err != nil { return err }
//	    process(img)
//	}
//
// Requires a registered decoder for the source level's
// Compression. Returns ErrCodecNotRegistered on the first Next()
// call if no inspector is registered.
func (s *Slide) ScaledStrips(
    l0Rect image.Rectangle,
    outSize image.Point,
    stripHeight int,
    opts ...StripOption,
) *StripIterator
```

### 4.2 StripIterator

```go
package opentile

import (
    "io"

    "github.com/wsilabs/opentile-go/decoder"
)

// StripIterator yields horizontal strips of a slide scaled to a
// target output resolution. Not safe for concurrent use; one
// goroutine drives Next() / Close() per iterator.
type StripIterator struct { /* unexported */ }

// Next returns the next strip. Returns io.EOF when all strips are
// exhausted. Other errors are real failures (codec, I/O,
// cancellation).
//
// The returned *decoder.Image has dimensions:
//   - Width: outSize.X (always)
//   - Height: stripHeight, except possibly the last strip
//     which may be shorter if outSize.Y is not a multiple of
//     stripHeight.
//
// The returned Image is owned by the caller; modifying it is safe.
// Subsequent Next() calls return fresh Image allocations (no
// buffer reuse in v0.26 — pool reuse is a future optimization).
func (it *StripIterator) Next() (*decoder.Image, error)

// Close releases the iterator's workers + tile cache. Safe to call
// multiple times. Calling Close before EOF cancels in-flight work
// cleanly. After Close, Next returns io.ErrClosedPipe.
//
// MUST be called to release resources. Defer Close immediately
// after ScaledStrips.
func (it *StripIterator) Close() error

// Strips returns the total number of strips this iterator will
// yield: ceil(outSize.Y / stripHeight). Computed at construction
// time; doesn't change as Next() is called.
//
// Useful for progress reporting (caller's strip-count is
// known up front).
func (it *StripIterator) Strips() int
```

### 4.3 StripOption + helpers

```go
package opentile

import (
    "context"

    "github.com/wsilabs/opentile-go/resample"
)

// StripOption configures a ScaledStrips iterator.
type StripOption func(*stripConfig)

// stripConfig is the resolved option set. Internal.
type stripConfig struct {
    workers    int               // runtime.NumCPU() default
    lookahead  int               // 2 default
    idctScale  int               // 0 = auto (resolved at iter init); 1/2/4/8 for explicit override
    kernel     resample.Kernel   // resample.Lanczos default
    ctx        context.Context   // context.Background() default
}

// WithStripWorkers sets the number of parallel source-tile decode
// workers. Default: runtime.NumCPU(). Values < 1 use 1.
func WithStripWorkers(n int) StripOption

// WithStripLookahead sets how many strips ahead the iterator
// pre-fetches source tiles for. Default: 2. 0 disables lookahead
// entirely (workers idle between Next() calls). Higher values
// trade memory for steady-state throughput on slow consumers.
func WithStripLookahead(strips int) StripOption

// WithStripIDCTScale overrides the auto-selected IDCT-time scale
// factor for JPEG sources. Valid: 1, 2, 4, 8. Default 0 = auto-
// select based on output downsample (see §4.4).
//
// Non-JPEG sources ignore this option silently.
func WithStripIDCTScale(scale int) StripOption

// WithStripKernel sets the resample kernel applied after the
// source-tile decode step (when IDCT alone doesn't reach the
// target output dims). Default: resample.Lanczos.
func WithStripKernel(k resample.Kernel) StripOption

// WithStripContext binds the iterator's worker pool to a
// cancellation context. Default: context.Background(). Cancelling
// ctx aborts in-flight Next() calls with ctx.Err().
//
// Workers also respond to *StripIterator.Close(); the option is
// for upstream cancellation (HTTP request cancellation, etc.).
func WithStripContext(ctx context.Context) StripOption
```

### 4.4 Auto IDCT scale selection

For JPEG-compressed source levels, the library auto-selects the
IDCT scale factor unless overridden via WithStripIDCTScale. The
selection runs once at iterator construction:

```
D = max(l0Rect.Dx() / outSize.X, l0Rect.Dy() / outSize.Y)
   * (1.0 / source_level.Downsample)

if D < 2:  scale = 1
elif D < 4:  scale = 2
elif D < 8:  scale = 4
else:  scale = 8
```

The IDCT scale layers ON TOP of source-level selection
(BestLevelForDownsample picks the highest-resolution pyramid
level whose Downsample ≤ requested D). Together they minimize
wasted decode work: BestLevelForDownsample reduces decode by
choosing a smaller level; IDCT further reduces by decoding that
level's JPEG tiles at 1/N scale; the resample step closes the
remaining gap.

Non-JPEG source levels (LZW, Deflate, JPEG 2000, WebP, AVIF,
JPEG XL, HTJ2K) skip the IDCT step; the downsample comes from
level selection alone, and the resample step closes any
remaining gap.

## 5. Implementation outline

### 5.1 Iterator construction

`ScaledStrips(l0Rect, outSize, stripHeight, opts...)`:

1. Resolve `stripConfig` from opts (defaults + overrides).
2. Validate: stripHeight > 0, outSize.X > 0, outSize.Y > 0,
   l0Rect non-empty, lookahead ≥ 0, workers > 0.
3. Clip l0Rect to slide bounds; if entirely OOB, the iterator
   still constructs successfully (Next() will yield white strips
   per ReadRegion semantics — there's no useful work to do, but
   the contract holds).
4. Compute downsample `D` from l0Rect and outSize.
5. Call `BestLevelForDownsample(D)` to choose source level.
6. For JPEG levels: if cfg.idctScale == 0 (auto), apply the §4.4
   selection logic; else use cfg.idctScale.
7. Construct internal `*tileCache`, worker pool, lookahead
   coordinator.
8. Return `&StripIterator{...}`.

### 5.2 Internal pipeline

Three concurrent components live behind the iterator:

**Lookahead coordinator** (1 goroutine):
- Walks output strips in order (0, 1, 2, ...).
- For strip N currently within `[currentStripIdx, currentStripIdx + lookahead]`:
  - Compute the source-level tile coverage.
  - Enqueue any unique tile coords not already requested.
- Blocks when current strip + lookahead are all dispatched (no
  new work to enqueue).
- Notified when currentStripIdx advances (via Next() returning).

**Decode workers** (N goroutines, default NumCPU):
- Each pulls (tileX, tileY) requests from the input channel.
- Calls `slide.ImageDecodedTile(image, sourceLevel, tx, ty,
  WithScale(idctScale), WithFormat(PixelFormatRGB))`.
- Stores result in the tile cache, signals waiters on that key.
- On context cancellation: drain channel and exit cleanly.

**Tile cache** (per-iterator, owned by the iterator):
- LRU bounded by tile count (default: `workers * (lookahead + 1) * tilesPerStripWidth`).
- Each entry: `(tileKey → decodedTile, refCount, signal)`.
- Eviction policy: only evict entries with refCount == 0. If
  capacity is hit while all entries are referenced, the lookahead
  pauses until the consumer advances.

**Strip assembly** (synchronous, in `Next()`):
- Compute strip's source-level coordinate range and tile coverage.
- For each covering tile, fetch from cache (blocking until the
  worker has decoded it).
- Allocate output strip `*decoder.Image` (outSize.X × stripHeight,
  RGB by default; RGBA via future option).
- Blit each tile's contribution into the strip's pixel buffer.
- If level-resolution rect != strip resolution: resample via
  `resample.ImageInto` with the configured kernel.
- Decrement refCount on consumed tiles (lookahead can evict).
- Return strip image.

### 5.3 Concurrency contract

- All exported methods on `*StripIterator` are called from one
  goroutine (the iterator is not safe for concurrent use).
- Internal workers + lookahead + cache use sync.Mutex /
  sync.Cond / channels for coordination.
- `Close()` is idempotent and safe from any goroutine
  (specifically: a separate goroutine can call Close() while the
  primary goroutine is mid-Next; Next() will return with
  io.ErrClosedPipe rather than the value being computed).
- Cancellation via WithStripContext: ctx.Done() shuts down workers
  and propagates ctx.Err() to the next Next() call.

### 5.4 Error model

- I/O failure during a tile decode: error is stored on the tile's
  cache entry; when strip assembly tries to consume that tile, it
  surfaces the error from `Next()`. Other workers continue (so
  later strips may still complete if they don't need the failed
  tile).
- ErrCodecNotRegistered: same path — surfaces on the first strip
  that requires a tile decode at the affected level.
- Context cancellation: workers shut down, next `Next()` returns
  `ctx.Err()`.
- Close() with workers still running: graceful drain + return the
  first error encountered (or nil if no errors).
- Out-of-bounds L0 rect: auto-clipped to slide bounds at
  construction; if fully empty, all strips are white.

## 6. Sentinel errors

Reuses existing v0.22-v0.25 sentinels:

- `decoder.ErrCodecNotRegistered` — wrapped from `DecodedTile`.
- `ErrRegionEmpty` — NOT used for ScaledStrips. Empty l0Rect is
  not an error; iterator yields all-white strips.

New (potentially):

- `io.EOF` — standard library; signals exhaustion. Reused, not
  redefined.
- `io.ErrClosedPipe` — standard library; returned by Next() after
  Close(). Reused.

No new opentile-go sentinel errors are needed.

## 7. Performance

### 7.1 Targets

Steady-state CPU utilization should saturate `workers` cores
during a long iteration on a JPEG-compressed Aperio slide
(lookahead ≥ 2 keeps the pipeline full). Specific throughput
goal: within 20% of libvips dzsave on the same slide and the same
output resolution. Defer formal benchmarks to a follow-up after
first working impl.

### 7.2 Memory bounds

Per-iterator memory:
- Tile cache: at most `(workers * (lookahead + 1) * tilesPerStripWidth)` decoded tiles. For a typical 16-worker, 2-lookahead, 100-tile-wide strip: ~3200 tiles × 256×256×3 bytes ≈ 600 MB peak. Defer reducing this to a future cache-tuning option.
- One in-flight strip output: `outSize.X × stripHeight × 3` bytes. Small (typically ~1 MB).
- Worker scratch: bounded by decoder.Image allocations.

Total: dominated by tile cache. ~600 MB for a wide thumbnail; smaller for narrow output.

### 7.3 Benchmark surface

`go test -bench` infrastructure to add after first working impl.
Not blocking on v0.26 ship.

## 8. Testing strategy

### 8.1 Unit tests (no fixtures required)

`strip_iterator_test.go`:

- **TestScaledStrips1x1Slide** — synthetic 1-tile slide (e.g., 256×256), 256×256 output, stripHeight 256: 1 strip, byte-equal to DecodedTile.
- **TestScaledStripsMultiStrip** — 256×512 output, stripHeight 64: 8 strips of 256×64.
- **TestScaledStripsShortLastStrip** — outSize.Y=100, stripHeight=64: 2 strips, last is 256×36.
- **TestScaledStripsStripsCount** — `Strips()` returns the right count for various outSize.Y / stripHeight combinations.
- **TestScaledStripsCloseBeforeEOF** — Close() before draining, verify no goroutine leak (`runtime.NumGoroutine()` settles within 100ms).
- **TestScaledStripsCloseIdempotent** — Close(), Close() — second is no-op.
- **TestScaledStripsAfterCloseError** — Next() after Close() returns io.ErrClosedPipe.
- **TestScaledStripsContextCancel** — WithStripContext + ctx.Cancel(); next Next() returns ctx.Err().

### 8.2 Integration tests (fixture-gated)

`strip_iterator_integration_test.go`:

- **TestScaledStripsWholeSlide** — open CMU-1-Small-Region.svs, ScaledStrips on whole-slide L0 rect, outSize=512×512, stripHeight=64: iterate all strips, verify dimensions + no errors.
- **TestScaledStripsThumbnail** — outSize=128×128 (full slide downsample): iterate; verify single-strip output (stripHeight=128).
- **TestScaledStripsAutoIDCT** — JPEG slide, verify auto IDCT chooses scale=4 for 4× downsample (instrumented via debug field or just checking output dims match expected post-IDCT).
- **TestScaledStripsCrossFormat** — table-driven across all available sample formats (SVS, NDPI, Philips, OME-TIFF, BIF, LeicaSCN, generic-TIFF, COG-WSI, SZI). Each: open slide, iterate strips on a small output, verify no errors + non-empty output.
- **TestScaledStripsErrCodec** — open a slide without blank-importing decoder/all (separate test binary), iterate, verify first Next() returns ErrCodecNotRegistered.

### 8.3 Concurrency / race tests

- All tests above run under `-race` (CI default).
- Specific stress test: spawn 8 concurrent ScaledStrips iterators on the same slide, each iterating to completion. Verifies no data races between iterator instances.

### 8.4 Coverage targets

- `strip_iterator.go` ≥ 80%.
- `strip_cache.go` ≥ 90% (concurrency paths are critical).
- `strip_options.go` ≥ 95% (simple option setters).
- Integration tests fill in the cross-format coverage.
