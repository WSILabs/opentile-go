# opentile-go v0.24 — Level Value-Type + Decoded Tiles

**Status:** Design approved 2026-05-25.

## 1. Goal

Finish the strategic-doc Level/Image reshape: convert `Level` and `Image`
from interfaces with methods to value-type structs (inspection fields
only); move tile reads (raw and decoded) onto `*Slide`. Add decoded-tile
methods that dispatch through the `decoder/` package introduced in
v0.22.

After v0.24:
- `Level` and `Image` are value-type structs with no methods.
- Every tile read goes through `*Slide` methods that take a level index
  (plus an image index for multi-image OME-TIFF).
- Callers wanting decoded pixels call `*Slide.DecodedTile(...)` instead
  of doing the `Tile() + decoder.Get()` dance themselves.

This is the second installment of the v1.0 *Slide redesign (the first
was v0.23's `Tiler` → `*Slide` cut).

## 2. Scope

In scope for v0.24:

- `Level` becomes a value-type struct (fields only).
- `Image` becomes a value-type struct (Name + Index + Levels).
- New `*Slide` methods:
  - `RawTile(level, tx, ty int) ([]byte, error)` (was `Level.Tile`)
  - `RawTileInto(level, tx, ty int, dst []byte) (int, error)` (was `Level.TileInto`)
  - `ImageRawTile(image, level, tx, ty int) ([]byte, error)`
  - `ImageRawTileInto(image, level, tx, ty int, dst []byte) (int, error)`
  - `DecodedTile(level, tx, ty int, opts ...DecodeOption) (*decoder.Image, error)`
  - `DecodedTileInto(level, tx, ty int, dst *decoder.Image, opts ...DecodeOption) error`
  - `ImageDecodedTile(image, level, tx, ty int, opts ...DecodeOption) (*decoder.Image, error)`
  - `ImageDecodedTileInto(image, level, tx, ty int, dst *decoder.Image, opts ...DecodeOption) error`
- New `DecodeOption` functional-option type with `WithFormat` +
  `WithScale` helpers.
- Internal `format.Reader` interface gains the same tile-access methods
  (RawTile, ImageRawTile, etc.) that *Slide forwards to.
- Every format reader (svs, ndpi, philipstiff, ometiff, bif, ife,
  generictiff, leicascn, szi, cogwsi) refactored to populate value-type
  Level + Image at Open time and route tile reads through (image,
  level, tx, ty) dispatch.
- Lockstep wsitools v0.12.0 migration (separate release) updating every
  `slide.Levels()[i].Tile(tx, ty)` → `slide.RawTile(i, tx, ty)` and
  every field-method call `level.Size()` → field access `level.Size`.

Out of scope (deferred):

- `ReadRegion` / `ReadRegionScaled` (arbitrary L0 rectangle reads
  spanning multiple tiles). v0.25.
- `ScaledStrips` strip iterator with parallel decode + tile cache +
  lookahead. v0.26.
- `Thumbnail`, `BestLevelForDownsample`, `Bounds`, `BackgroundColor`.
  v0.27.
- `AssociatedImage.Decoded()` accessor. v0.28.
- Streaming `downsample` retrofit in wsitools. Separate ticket.
- Auto-importing `decoder/all` from `opentile`. Deliberate non-goal —
  keeps the default footprint small for callers who only need raw
  bytes.

Non-goals:

- Backward compatibility for the Level/Image interfaces. wsitools
  migrates in lockstep as v0.12.0; no shim window.
- Behavior change in tile-byte output. Every format reader's raw tile
  bytes stay identical to v0.23.

## 3. Architecture overview

```
opentile-go/
    slide.go                         *Slide gets 8 new tile-read methods;
                                     delegates to format.Reader
    image.go                         Image + Level become value-type structs;
                                     interfaces deleted
    decode_options.go                DecodeOption type + WithFormat / WithScale
    slide_decoded_tile.go            DecodedTile + DecodedTileInto +
                                     ImageDecodedTile + ImageDecodedTileInto
                                     (the codec-dispatch helpers)
    slide_test.go                    *Slide method tests

    internal/format/
        reader.go                    Reader interface gains RawTile,
                                     ImageRawTile (+ Into variants);
                                     drops Level / Image methods

    formats/svs/                     internal slide type implements new
                                     Reader; eagerly populates []Level
                                     value-type slice at Open time
    formats/ndpi/                    same
    formats/philipstiff/             same
    formats/ometiff/                 same (multi-image — populates []Image
                                     with per-image []Level slices)
    formats/bif/                     same
    formats/ife/                     same
    formats/generictiff/             same
    formats/leicascn/                same
    formats/szi/                     same
    formats/cogwsi/                  same
```

The format-specific reader internally still owns the tile-read code
(per-level dispatch, JPEG-tables-prefix splicing, NDPI strip-to-tile
synthesis, etc.). What changes is HOW callers reach it:

- v0.23: caller does `slide.Levels()[i].Tile(tx, ty)` → Level
  interface's Tile method routes to the format-internal handler.
- v0.24: caller does `slide.RawTile(i, tx, ty)` → *Slide delegates to
  `format.Reader.RawTile(0, i, tx, ty)` (image 0) → format reader
  routes to the same internal handler.

Net: the slow path (tile-read I/O + JPEG-tables splicing) is unchanged;
only the dispatch shape moves.

### DecodedTile dispatch flow

```
*Slide.DecodedTile(level, tx, ty, opts...)
  → resolve effective DecodeOption (Format + Scale, defaults applied)
  → *Slide.RawTile(level, tx, ty)              // get compressed bytes
  → look up Level.Compression
  → decoder.GetByCompressionTag(compression)   // factory from registry
  → if !ok: return ErrCodecNotRegistered (with rebuild diagnostic)
  → factory.New() → Decoder
  → defer Decoder.Close()
  → Decoder.Decode(rawBytes, decoder.DecodeOptions{Scale, Format})
  → return *decoder.Image
```

DecodedTileInto: same flow but passes `opts.Dst` so the decoder writes
into the caller's pre-allocated `*decoder.Image`.

The codec registry comes from the `decoder/` package introduced in
v0.22. opentile-go does NOT blank-import `decoder/all` itself —
consumers add one blank import:

```go
import (
    opentile "github.com/wsilabs/opentile-go"
    _ "github.com/wsilabs/opentile-go/formats/all"
    _ "github.com/wsilabs/opentile-go/decoder/all"  // new in v0.24 for DecodedTile
)
```

Or specific subpackages for lighter cgo footprints (e.g., just
`decoder/jpeg` if the consumer only handles JPEG slides).

## 4. The Level value-type

```go
package opentile

// Level is value-type pyramid-level metadata. All fields are
// inspection-only (read at *Slide.Open time). Tile reads use
// *Slide.RawTile / *Slide.DecodedTile (takes level index).
type Level struct {
    // Index is the 0-based index of this level within the parent
    // Image's Levels slice. Pass to *Slide.RawTile(image, Index, tx, ty).
    Index int

    // PyramidIndex is the pyramid-group index for multi-image formats.
    // Single-image formats always have PyramidIndex = 0. OME-TIFF
    // multi-image files preserve the per-image series identifier here.
    PyramidIndex int

    // Size is the pixel dimensions of this level (Width × Height).
    Size Size

    // TileSize is the tile dimensions used by this level.
    TileSize Size

    // Grid is the tile grid dimensions: (Size.W + TileSize.W - 1) / TileSize.W
    // by similar for H. Pre-computed for convenience.
    Grid Size

    // Compression identifies the codec for tile bytes at this level.
    // Used by *Slide.DecodedTile to dispatch to the right decoder.
    Compression Compression

    // MPP is microns-per-pixel at this level (X and Y; usually equal).
    // Zero value if the slide doesn't carry MPP metadata.
    MPP SizeMm

    // FocalPlane is the z-position in microns for multi-focal-plane
    // sources. Zero value for 2D slides.
    FocalPlane float64

    // TileOverlap is the per-tile overlap for formats that use
    // overlapping tiles (NDPI in some configurations). Zero for
    // non-overlapping tile formats.
    TileOverlap image.Point
}
```

## 5. The Image value-type

```go
package opentile

// Image identifies one pyramid group within a slide. Single-image
// formats (SVS, NDPI, Philips, BIF, IFE, Leica SCN, generic-TIFF,
// SZI, COG-WSI) carry a single Image. OME-TIFF carries multiple.
type Image struct {
    // Name identifies this image (OME-TIFF series Name attribute,
    // or empty for single-image formats).
    Name string

    // Index is the 0-based index of this image within the slide.
    // Pass to *Slide.ImageRawTile(Index, level, tx, ty).
    Index int

    // Levels is the pyramid for this image, finest-to-coarsest by
    // convention (level 0 is the full-resolution base).
    Levels []Level
}
```

## 6. `DecodeOption`

Functional-options pattern, matching existing Go conventions in
opentile-go (`Option` for `Open`):

```go
package opentile

import "github.com/wsilabs/opentile-go/decoder"

// DecodeOption configures a *Slide.DecodedTile / DecodedTileInto call.
type DecodeOption func(*decodeConfig)

type decodeConfig struct {
    format decoder.PixelFormat // default: PixelFormatRGB
    scale  int                  // JPEG IDCT scale (1, 2, 4, 8); default 1
}

// WithFormat sets the requested output pixel format. Defaults to
// PixelFormatRGB (3 bytes per pixel; alpha-free, the typical WSI shape).
// PixelFormatRGBA is also universally supported by the v0.22 decoders.
func WithFormat(f decoder.PixelFormat) DecodeOption {
    return func(c *decodeConfig) { c.format = f }
}

// WithScale sets the IDCT-time scale factor (JPEG decoders only).
// Valid values: 1, 2, 4, 8. Non-JPEG sources return ErrUnsupportedScale
// if Scale != 1. Use this for fast thumbnail-class downsampling on
// JPEG-encoded WSIs.
func WithScale(s int) DecodeOption {
    return func(c *decodeConfig) { c.scale = s }
}
```

## 7. *Slide method shapes

The post-survey decision (2026-05-25) is to migrate EVERY Level
interface method onto *Slide, not just Tile/TileInto. This includes
the v0.13 splice-prefix optimization family (TileMaxSize, TilePrefix,
TileBodyInto, TileBodyMaxSize, TileReader) and the Go 1.23
range-over-function tile iterator (Tiles → RangeTiles).

```go
// Raw tile access — image 0 shortcut for the single-image case.
func (s *Slide) RawTile(level, tx, ty int) ([]byte, error)
func (s *Slide) RawTileInto(level, tx, ty int, dst []byte) (n int, err error)

// Multi-image raw tile access.
func (s *Slide) ImageRawTile(image, level, tx, ty int) ([]byte, error)
func (s *Slide) ImageRawTileInto(image, level, tx, ty int, dst []byte) (n int, err error)

// Decoded tile access — image 0 shortcut. Requires a registered
// decoder for the level's Compression; returns ErrCodecNotRegistered
// otherwise.
func (s *Slide) DecodedTile(level, tx, ty int, opts ...DecodeOption) (*decoder.Image, error)
func (s *Slide) DecodedTileInto(level, tx, ty int, dst *decoder.Image, opts ...DecodeOption) error

// Multi-image decoded tile access.
func (s *Slide) ImageDecodedTile(image, level, tx, ty int, opts ...DecodeOption) (*decoder.Image, error)
func (s *Slide) ImageDecodedTileInto(image, level, tx, ty int, dst *decoder.Image, opts ...DecodeOption) error

// Splice-prefix optimization (v0.13-era) — for tile-server consumers
// that strip the shared JPEG-tables prefix once per level then splice
// onto each tile body.
func (s *Slide) TilePrefix(level int) []byte
func (s *Slide) ImageTilePrefix(image, level int) []byte
func (s *Slide) TileMaxSize(level int) int
func (s *Slide) ImageTileMaxSize(image, level int) int
func (s *Slide) TileBodyMaxSize(level int) int
func (s *Slide) ImageTileBodyMaxSize(image, level int) int
func (s *Slide) TileBodyInto(level, tx, ty int, dst []byte) (n int, err error)
func (s *Slide) ImageTileBodyInto(image, level, tx, ty int, dst []byte) (n int, err error)

// Streaming reader access — for consumers that want to pipe tile
// bytes without materializing a []byte first.
func (s *Slide) TileReader(level, tx, ty int) (io.ReadCloser, error)
func (s *Slide) ImageTileReader(image, level, tx, ty int) (io.ReadCloser, error)

// Range-over-function tile iterator (Go 1.23+). Yields every tile in
// the given level, in raster order. ctx is the cancellation context.
func (s *Slide) RangeTiles(ctx context.Context, level int) iter.Seq2[TilePos, TileResult]
func (s *Slide) ImageRangeTiles(ctx context.Context, image, level int) iter.Seq2[TilePos, TileResult]
```

`TileAt(coord TileCoord)` is dropped — `Tile(coord.X, coord.Y)` is the
caller pattern; the explicit struct argument is a marginal convenience
that doesn't earn its API surface.

`Tiles()` is renamed `RangeTiles()` to match Go's range-over-function
naming conventions and to disambiguate from the inspection-style
"tiles" word that might otherwise suggest a slice return.

`Levels()` and `Level(i)` shortcuts continue to work — they now return
value-type Level (not interface). `Images()` continues to work — returns
value-type Image.

### `RawTile` is a shortcut for `ImageRawTile(0, ...)`

```go
func (s *Slide) RawTile(level, tx, ty int) ([]byte, error) {
    return s.r.ImageRawTile(0, level, tx, ty)
}
```

Same for the other three shortcut pairs.

## 8. Sentinel errors

```go
package opentile

import "errors"

// ErrCodecNotRegistered is returned by DecodedTile / DecodedTileInto
// when no decoder is registered for the level's Compression. The
// wrapping error message names the compression and the suggested
// blank-import that fixes it.
var ErrCodecNotRegistered = errors.New("opentile: codec not registered for this slide's tile compression")
```

Example wrapped error:

```
opentile: codec not registered for this slide's tile compression: jpeg2000.
Blank-import github.com/wsilabs/opentile-go/decoder/jpeg2000 or
github.com/wsilabs/opentile-go/decoder/all to enable. (opentile.ErrCodecNotRegistered)
```

## 9. format.Reader interface changes

Drops Level + Image methods (since those become value-types). Adds
tile-access methods:

```go
package format

type Reader interface {
    Format() opentile.Format
    Images() []opentile.Image            // returns value-type Image now
    Level(image, level int) (opentile.Level, error)
    Associated() []opentile.AssociatedImage
    Metadata() opentile.Metadata
    ICCProfile() []byte
    WarmLevel(image, level int) error    // gains image index

    // Tile access — image + level both indices.
    ImageRawTile(image, level, tx, ty int) ([]byte, error)
    ImageRawTileInto(image, level, tx, ty int, dst []byte) (int, error)

    Close() error
}
```

Note: `Levels()` shortcut is on `*Slide` (returns
`s.r.Images()[0].Levels`); no longer on Reader.

## 10. Migration mechanics

### Within opentile-go (per-format work)

Each `formats/<name>` package:

1. Internal Reader-implementing type currently constructs Image / Level
   interface instances lazily. v0.24: build value-type `[]Image` and
   `[]Level` slices at Open time, storing them in the reader struct.
2. The Tile method (currently on Level) moves to the reader's
   `ImageRawTile(image, level, tx, ty)`. Routing logic stays the
   same — just one more level of indirection (image index).
3. Drop the Level / Image interface implementations entirely.

Single-image formats (everything except OME-TIFF): always accept image
== 0; return `ErrImageIndexOutOfRange` for any other value.

### Within wsitools (v0.12.0)

Every call site:

| v0.23                                       | v0.24                              |
|---------------------------------------------|------------------------------------|
| `slide.Levels()[i].Tile(tx, ty)`            | `slide.RawTile(i, tx, ty)`         |
| `slide.Levels()[i].TileInto(tx, ty, dst)`   | `slide.RawTileInto(i, tx, ty, dst)`|
| `slide.Levels()[i].Size()`                  | `slide.Levels()[i].Size`           |
| `slide.Levels()[i].TileSize()`              | `slide.Levels()[i].TileSize`       |
| `slide.Levels()[i].Compression()`           | `slide.Levels()[i].Compression`    |
| `slide.Levels()[i].Grid()`                  | `slide.Levels()[i].Grid`           |
| (anywhere using opentile.Level as interface)| value-type opentile.Level          |

Most wsitools call sites are method-call → field-access changes.
Mechanical.

### Release sequencing

1. opentile-go v0.24.0 first.
2. wsitools v0.12.0 follows (bump dep + migrate).

## 12. Testing strategy

### Existing tests preserved

All existing format-package unit tests + integration tests (parity
oracle, TileBodyReconstitutionInvariant, etc.) continue to pass after
the migration. They become a key acceptance gate: if any byte-equality
test fails, the v0.24 migration changed behavior somewhere.

Migration of these tests is mechanical — replace
`level.Tile(tx, ty)` → `slide.RawTile(i, tx, ty)` (often the test
already has the slide handle nearby).

### New tests

- `slide_test.go` adds:
  - `TestRawTileFirstImage` — RawTile(0, 0, 0) on a single-image
    sample returns bytes equal to historical Level.Tile(0, 0).
  - `TestImageRawTile` — multi-image OME-TIFF sample; ImageRawTile(0,
    ...) and ImageRawTile(1, ...) produce different bytes (verifies
    the image dimension is exercised).
  - `TestDecodedTileWithoutDecoder` — DecodedTile with no decoder
    blank-imported returns ErrCodecNotRegistered with the correct
    rebuild diagnostic.
  - `TestDecodedTileWithJPEGDecoder` — blank-import decoder/jpeg, call
    DecodedTile on a JPEG-compressed SVS sample, verify output is a
    non-empty *decoder.Image with the expected dimensions.
  - `TestDecodedTileScaleFactor` — WithScale(2) on a JPEG source
    returns half-dimensions output (IDCT-time downsample).
- `decode_options_test.go` — functional options apply correctly;
  defaults are RGB + scale 1.

### Format-reader unit-test updates

Each `formats/<name>` package's tests get a small refactor — wherever
they previously exercised the Tile interface method, they now go
through the format reader's ImageRawTile. No semantic change in what's
being tested.

## 13. Backward compatibility

None. This is a clean break for the Level/Image interface contract.

- The only consumer is wsitools; migrates in lockstep as v0.12.0.
- No deprecation shim.

Any code that still calls `slide.Levels()[i].Tile(...)` after v0.24
fails to compile. The migration table in §11 and the BREAKING
CHANGELOG entry are the primary migration documentation.
