# opentile-go v0.25 — ReadRegion + ReadRegionScaled

**Status:** Design approved 2026-05-25.

## 1. Goal

Add arbitrary-rectangle region reads to `*Slide`. After v0.25, callers
can read a rectangular pixel region that spans multiple tiles at a
single level (`ReadRegion`) or specify an L0 rectangle plus a target
output resolution and let the library pick the best source level and
resample (`ReadRegionScaled`). This is the openslide-equivalent
surface most pathology consumers expect.

v0.25 is the third installment of the v1.0 *Slide redesign (after
v0.23's Tiler→*Slide cut and v0.24's Level value-type + DecodedTile).

## 2. Scope

In scope for v0.25:

- New `*Slide` methods:
  - `ReadRegion(level, x, y, w, h int, opts ...DecodeOption) (*decoder.Image, error)`
  - `ReadRegionInto(level, x, y int, dst *decoder.Image, opts ...DecodeOption) error`
  - `ImageReadRegion(image, level, x, y, w, h int, opts ...DecodeOption) (*decoder.Image, error)`
  - `ImageReadRegionInto(image, level, x, y int, dst *decoder.Image, opts ...DecodeOption) error`
  - `ReadRegionScaled(l0x, l0y, l0w, l0h, outW, outH int, opts ...DecodeOption) (*decoder.Image, error)`
  - `ReadRegionScaledInto(l0x, l0y, l0w, l0h int, dst *decoder.Image, opts ...DecodeOption) error`
  - `ImageReadRegionScaled(image, l0x, l0y, l0w, l0h, outW, outH int, opts ...DecodeOption) (*decoder.Image, error)`
  - `ImageReadRegionScaledInto(image, l0x, l0y, l0w, l0h int, dst *decoder.Image, opts ...DecodeOption) error`
  - `BestLevelForDownsample(downsample float64) int`
  - `ImageBestLevelForDownsample(image int, downsample float64) int`
- New `WithResampleKernel(k resample.Kernel) DecodeOption` helper.
- New sentinel `ErrRegionEmpty` returned when the requested rectangle
  has no in-bounds pixels.
- Out-of-bounds handling: auto-clip + white-fill (0xFF, 0xFF, 0xFF).
- v0.13.0+ wsitools utility commands (`region`, future) become
  feasible on this surface.

Out of scope (deferred):

- `ScaledStrips` strip iterator with parallel decode + tile cache +
  lookahead. v0.26 — the libvips-speed piece.
- Decoded-tile caching across ReadRegion calls (each call decodes
  every source tile fresh). v0.26 strip iterator addresses this.
- `Thumbnail`, `Bounds()`, `BackgroundColor()` accessors. v0.27.
- `AssociatedImage.Decoded()`. v0.28.
- The openslide-convention mixed-coord `read_region((x, y), level,
  (w, h))` shape. Intentionally NOT shipped per design decision; the
  uniform-coord ReadRegion + L0-rect ReadRegionScaled fully cover the
  use cases without the openslide footgun.

Non-goals:

- Backward-compatibility shims. v0.25 is purely additive over v0.24.
- Changing v0.24 methods (Tile reads, DecodedTile, Level/Image
  value-types). All preserved.

## 3. Architecture overview

```
opentile-go/
    slide_region.go              ReadRegion + Into + Image variants
    slide_region_scaled.go       ReadRegionScaled + Into + Image variants
    slide_best_level.go          BestLevelForDownsample + Image variant
    decode_options.go            (modified) adds WithResampleKernel
    errors.go                    (modified) adds ErrRegionEmpty
    slide_region_test.go         ReadRegion unit + integration tests
    slide_region_scaled_test.go  ReadRegionScaled tests + edge cases
```

ReadRegion is implemented entirely on `*Slide` using v0.24's
`ImageDecodedTile`. Format readers are NOT touched — the new
methods are pure compositions over the existing decoded-tile API
plus blit + resample logic. This is a smaller refactor than v0.24.

## 4. Coordinate semantics

All ReadRegion parameters use **the level's own pixel resolution**.
No mixed coord systems. Anyone coming from openslide-python must
explicitly divide by the level's downsample factor at the call site:

```go
// openslide-python:   slide.read_region((l0x, l0y), level, (w, h))
// opentile-go v0.25:  slide.ReadRegion(level, l0x/level.Downsample, l0y/level.Downsample, w, h)
```

The explicit division is intentional. It surfaces the coordinate-
space translation at the call site rather than burying it in mixed-
convention parameters.

ReadRegionScaled is the OTHER end of the spectrum: ALL four position
+ dimension args are L0 coords, plus a target output resolution.
This is the actual openslide use case (specify L0 rectangle + render
size), in cleaner shape.

## 5. Method signatures

### `ReadRegion(level, x, y, w, h)`

```go
// ReadRegion returns the decoded pixel data for the rectangle
// (x, y)-(x+w, y+h) at the given level. ALL FOUR coords/dims are
// at the level's own resolution. Use ReadRegionScaled if you have
// L0 coords or want arbitrary output dimensions.
//
// The rectangle may extend beyond the level's bounds; out-of-bounds
// pixels are white-filled (0xFF, 0xFF, 0xFF). When v0.27 ships
// BackgroundColor(), the fill becomes scanner-aware.
//
// Returns ErrRegionEmpty if the entire rectangle is outside the
// level's bounds.
//
// Requires a registered decoder for the level's Compression — same
// constraint as DecodedTile.
//
// Internally spans the relevant tiles and decodes each once.
// Adjacent ReadRegion calls do NOT share a decoded-tile cache;
// for high-throughput patterns use the v0.26 ScaledStrips iterator
// when it ships.
func (s *Slide) ReadRegion(level, x, y, w, h int, opts ...DecodeOption) (*decoder.Image, error)
```

### `ReadRegionInto`

```go
// ReadRegionInto decodes a region into a caller-provided destination
// Image. The (x, y) coords are at the level's resolution; the
// region size is taken from dst.Width × dst.Height. dst.Format may
// be RGB or RGBA.
//
// dst.Pix is overwritten in full (every pixel set by the decode +
// fill logic). Pre-allocate dst to dst.Width × dst.Height × bpp.
func (s *Slide) ReadRegionInto(level, x, y int, dst *decoder.Image, opts ...DecodeOption) error
```

### `ImageReadRegion` / `ImageReadRegionInto`

```go
// ImageReadRegion is the multi-image variant of ReadRegion. For
// single-image formats, accept image=0 only.
func (s *Slide) ImageReadRegion(image, level, x, y, w, h int, opts ...DecodeOption) (*decoder.Image, error)
func (s *Slide) ImageReadRegionInto(image, level, x, y int, dst *decoder.Image, opts ...DecodeOption) error
```

### `ReadRegionScaled(l0x, l0y, l0w, l0h, outW, outH)`

```go
// ReadRegionScaled reads an L0-coord rectangle and resamples it
// to (outW, outH). The library picks the best source pyramid level
// via BestLevelForDownsample, reads at that level, then resamples.
//
// All input coords (l0x, l0y, l0w, l0h) are at L0 (full-resolution)
// coordinates. Output dimensions (outW, outH) are the desired final
// pixel size — any value, regardless of level resolutions.
//
// Out-of-bounds: the L0 rectangle is auto-clipped to slide bounds
// before level selection. Out-of-bounds pixels in the output are
// white-filled.
//
// Use WithResampleKernel to choose the resample quality. Default:
// resample.Lanczos. Use WithFormat / WithScale as with DecodedTile.
//
// Returns ErrRegionEmpty if the L0 rectangle has no in-bounds area.
func (s *Slide) ReadRegionScaled(l0x, l0y, l0w, l0h, outW, outH int, opts ...DecodeOption) (*decoder.Image, error)
func (s *Slide) ReadRegionScaledInto(l0x, l0y, l0w, l0h int, dst *decoder.Image, opts ...DecodeOption) error
```

### `ImageReadRegionScaled` / `ImageReadRegionScaledInto`

Multi-image variants. Image index first; remaining shape identical.

### `BestLevelForDownsample(downsample)`

```go
// BestLevelForDownsample returns the index of the largest pyramid
// level whose Downsample factor is ≤ the requested value. Used by
// ReadRegionScaled; public for caller use.
//
// Matches openslide.best_level_for_downsample semantics. Returns 0
// (L0) if every level's downsample exceeds the requested value
// (i.e., the caller wants higher resolution than the slide carries).
//
// For the first image. Use ImageBestLevelForDownsample for
// multi-image OME-TIFF.
func (s *Slide) BestLevelForDownsample(downsample float64) int
func (s *Slide) ImageBestLevelForDownsample(image int, downsample float64) int
```

## 6. `WithResampleKernel`

New `DecodeOption` for ReadRegionScaled:

```go
// WithResampleKernel chooses the resample kernel for ReadRegionScaled.
// Has no effect on ReadRegion (no resampling step).
//
// resample.Lanczos   — best perceptual quality (default)
// resample.Box       — fast integer-ratio downsampling, sharp
// resample.Bilinear  — fast, decent quality
// resample.Nearest   — fastest, ugly under downsampling
func WithResampleKernel(k resample.Kernel) DecodeOption
```

The `decodeConfig` struct gains a `kernel` field defaulting to
`resample.Lanczos`. ReadRegion ignores the kernel; ReadRegionScaled
consults it.

That `WithResampleKernel` is silently no-op for ReadRegion is a known
Go convention (options can be method-specific without separate Option
types). The alternative — a new `RegionOption` type — is more API
surface for marginal value.

## 7. Implementation

### `ReadRegion(level, x, y, w, h, opts...)`

```
1. Validate level in range; return ErrLevelOutOfRange if not.
2. Look up the Level value-type via slide.Levels()[level].
3. Compute clipped rectangle: intersect with (0, 0, level.Size.W, level.Size.H).
   If clipped rect is empty: return ErrRegionEmpty.
4. Allocate output *decoder.Image of (w, h) with opts.Format.
   Fill with white (0xFF, 0xFF, 0xFF) — the entire buffer.
5. Determine which tile coords overlap the clipped rectangle:
   tx_min = clippedX / TileSize.W
   ty_min = clippedY / TileSize.H
   tx_max = (clippedX + clippedW - 1) / TileSize.W
   ty_max = (clippedY + clippedH - 1) / TileSize.H
6. For (ty, tx) in [ty_min, ty_max] x [tx_min, tx_max]:
   - tileImg = ImageDecodedTile(image, level, tx, ty, opts...)
   - Compute intersect of (tx*TileSize.W, ty*TileSize.H, TileSize.W, TileSize.H)
     with clipped output rect.
   - Blit the intersected region from tileImg into the output Image.
7. Return.
```

### `ReadRegionScaled(l0x, l0y, l0w, l0h, outW, outH, opts...)`

```
1. Validate outW, outH > 0.
2. Compute downsample = max(l0w/outW, l0h/outH).
3. level = BestLevelForDownsample(downsample).
4. Translate L0 rect to level rect:
   levelX = l0x / level.Downsample
   levelY = l0y / level.Downsample
   levelW = l0w / level.Downsample  (may be different from outW)
   levelH = l0h / level.Downsample
5. ReadRegion(level, levelX, levelY, levelW, levelH, opts...) → intermediate
6. If (levelW, levelH) != (outW, outH):
   resample.ImageInto(intermediate, outImg, opts.kernel)
   where outImg is allocated at (outW, outH) per opts.Format.
7. Return outImg.
```

### `BestLevelForDownsample(downsample)`

```
Iterate levels in increasing index order. Track the largest level
whose Downsample ≤ requested. Return its index. If none qualify,
return 0 (L0).
```

This matches openslide's logic verbatim.

### Blit helper (internal)

```go
// blitInto copies a rectangular sub-region of src into dst at the
// given destination position. Used by ReadRegion to compose tile
// outputs into the output buffer.
//
// src and dst must have the same Format (RGB or RGBA). srcRect is
// (srcX, srcY, srcW, srcH) in src's coord space; dstX/dstY is the
// top-left of the destination.
func blitInto(src *decoder.Image, srcX, srcY, srcW, srcH int, dst *decoder.Image, dstX, dstY int)
```

Pure-Go memcpy per row. Roughly 1-2 instructions per byte at modern
memory bandwidth — not a bottleneck.

## 8. Sentinel errors

```go
// ErrRegionEmpty is returned by ReadRegion / ReadRegionScaled when
// the requested rectangle has no in-bounds pixels.
var ErrRegionEmpty = errors.New("opentile: region has no in-bounds pixels")
```

Reuses `ErrCodecNotRegistered`, `ErrLevelOutOfRange`,
`ErrImageIndexOutOfRange` from v0.24. No other new sentinels.

## 9. Out-of-bounds behavior

The library auto-clips the requested rectangle to the level's bounds
before tile dispatch. Out-of-bounds pixels in the OUTPUT image are
filled with white (0xFF, 0xFF, 0xFF) at allocation time, then the
in-bounds tiles overwrite the corresponding portion.

If the rectangle has zero in-bounds intersection, `ErrRegionEmpty`
is returned (a non-empty white-fill is a probable bug; the explicit
error helps callers catch it).

Negative `x` / `y` are allowed (rectangle extends left/above the
slide). Large `x+w` / `y+h` are allowed (rectangle extends
right/below). The combined region must have non-zero overlap with
the slide; otherwise ErrRegionEmpty.

When v0.27 ships `BackgroundColor()`, the fill value becomes
scanner-aware. Until then: hardcoded white. Documented in the v0.25
release notes.

## 10. Multi-image semantics

OME-TIFF carries multiple pyramid groups. The `Image<X>` variants
take an image index; single-image formats accept only image=0.

For single-image formats (svs, ndpi, philipstiff, generictiff, bif,
ife, leicascn, szi, cogwsi), the non-Image methods are shortcuts for
the `Image<X>(0, ...)` form. Multi-image OME-TIFF callers use the
explicit `Image<X>` methods.

### Coordinate convention

opentile-go diverges from openslide.read_region's mixed-coord
convention (L0 origin + level-resolution size). Instead:

- `ReadRegion` uses **uniform level coords**: all four args at the
  requested level's resolution.
- `ReadRegionScaled` uses **uniform L0 coords + arbitrary output
  resolution**: the actual openslide use case in cleaner shape.

Translating from openslide-python:

```python
# Old: slide.read_region((l0_x, l0_y), level, (w, h))
# New (opentile-go):
slide.ReadRegion(level, l0_x // int(level.Downsample), l0_y // int(level.Downsample), w, h)
```

The division is intentional — explicit at the call site rather than
buried in mixed-convention parameters.

### Unchanged

- All v0.24 APIs (RawTile, DecodedTile, splice-prefix family).
- Format readers (no changes — region reads compose over DecodedTile).
- File output bytes from format readers — region reads are decode-only.

### Why this release

Per the v1.0 *Slide redesign strategic doc: region reads are the
openslide-equivalent surface most pathology consumers expect.
`ReadRegionScaled` specifically is what a tile-viewer or
thumbnail-extractor needs. v0.26 will add the high-throughput
ScaledStrips iterator with parallel decode + tile cache + lookahead;
v0.25 provides the per-region one-shot API for ad-hoc reads.
```

## 12. Testing strategy

### Unit tests

- `slide_region_test.go`:
  - `TestReadRegionFullTile` — read a region exactly aligned with a
    single tile boundary; verify output bytes match `DecodedTile`.
  - `TestReadRegionAcrossTileBoundary` — read a region spanning two
    tiles; verify the seam pixels are continuous with each tile's
    decoded content.
  - `TestReadRegionOutOfBoundsRightEdge` — region extending past the
    level's right edge; verify the in-bounds portion is correct +
    the out-of-bounds portion is white.
  - `TestReadRegionOutOfBoundsNegative` — region with negative x or
    y; verify the in-bounds portion is correct.
  - `TestReadRegionEntirelyOutOfBounds` — region with no in-bounds
    intersection; verify `ErrRegionEmpty`.
  - `TestReadRegionWithRGBA` — `WithFormat(PixelFormatRGBA)`; verify
    output has 4 bytes/pixel and alpha is 0xFF everywhere.
  - `TestReadRegionInto` — caller-provided dst Image; verify dst is
    fully overwritten.

- `slide_region_scaled_test.go`:
  - `TestReadRegionScaledIdentity` — outW == l0w / downsample of
    chosen level; verify no resample step occurs (output bytes
    identical to ReadRegion at that level).
  - `TestReadRegionScaledExplicitKernel` — verify Lanczos vs Box
    produces different output (sanity that the kernel is wired).
  - `TestReadRegionScaledTinyOutput` — outW=10, outH=10 on a large
    L0 rect; verifies downscale picks a low-res level + resample
    works on tiny dims.
  - `TestBestLevelForDownsample` — table-driven against the
    openslide reference behavior for various downsample values
    + level slice configurations.

### Integration tests

Append to existing parity test suite — ReadRegion + ReadRegionScaled
on every sample format (svs, ndpi, philipstiff, ometiff, bif, ife,
generictiff, leicascn, szi, cogwsi). Smoke test: open slide, read a
512x512 region at level 0 and 1, assert non-empty output, no errors.
Requires OPENTILE_TESTDIR.

### Coverage targets

- slide_region.go ≥85% line coverage.
- slide_region_scaled.go ≥80% (the resample path is exercised by
  one integration test per sample).
- BestLevelForDownsample table-driven test: ≥95% (cheap pure
  function).

## 13. Performance considerations

ReadRegion decodes EVERY overlapping tile, even when the rectangle
covers only a small fraction of each. For one-shot reads this is
fine. For sequential adjacent reads (a viewport pan, an ML inference
sliding window), each call re-decodes the same source tiles —
wasteful. The v0.26 ScaledStrips iterator + tile cache fixes this.

ReadRegionScaled adds a resample pass on top of ReadRegion's decode
work. Lanczos is the slowest kernel; Box / Bilinear are notably
faster if quality permits.

No benchmarks ship in v0.25. Add when wsitools' `region` command
lands and we have a realistic workload.

## 14. Backward compatibility

Purely additive over v0.24. No existing API changes. wsitools v0.13.0
(future) can adopt v0.25 by bumping the dep; no migration work
required at the existing call sites.
