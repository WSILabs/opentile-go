# opentile-go v0.23 — *Slide API Redesign

**Status:** Design approved 2026-05-24.

## 1. Goal

Replace opentile-go's public `Tiler` interface with a single `*Slide` struct
that owns the format-specific tile reader as an internal detail. This is
the first installment of the v1.0 redesign sketched in
`wsitools/docs/strategic-direction.md`. v0.23 ships only the surface
required to replace `Tiler` (identity + metadata + raw tile access);
decoded-tile methods, `ReadRegion`, and the strip iterator are deferred
to v0.24+.

**Why:** the current `Tiler` interface forces every format implementer to
grow in lockstep when we want to add new operations (decoded tiles,
region reads, scaled strips). Switching to a concrete `*Slide` struct
with the format reader as an unexported interface lets us add new
methods on `*Slide` without breaking format implementations.

The Go-idiomatic pattern: `*Slide` is a concrete struct (not an
interface); the format-specific reader becomes an unexported interface.
Architecture mirrors `*tls.Conn` over `net.Conn`, `*sql.DB` over a
driver, `*os.File` over an `fd`.

## 2. Scope

In scope for v0.23:

- New public `*Slide` type with: `OpenFile`, `Open`, `Close`, `Format`,
  `Metadata`, `Levels`, `Associated`, `TIFFTags`, `RawTile`, `RawTileInto`.
- New unexported `format.Reader` interface within opentile-go (lives in
  `internal/format/`); every format package implements it.
- Format-package constructors change shape: they return a
  `format.Reader` instead of an `opentile.Tiler`. Registration via the
  existing `formats/all` blank-import pattern is preserved.
- Delete `Tiler` interface, `OpenTiler` constructor, and any other
  public-surface code obsoleted by `*Slide`.
- Synchronized cut with wsitools v0.11.0 (which adopts the new API).

Out of scope (parked for later releases):

- Decoded tile access (`DecodedTile`, `DecodedTileInto`) — v0.24+.
- Region reads (`ReadRegion`, `ReadRegionScaled` and their `Into`
  variants) — v0.25+.
- Strip iterator (`ScaledStrips` with parallel decode, cache, lookahead)
  — v0.26 or later.
- Convenience methods (`Thumbnail`, `BestLevelForDownsample`, `Bounds`,
  `BackgroundColor`, `ICCProfile`) — incremental adds.
- `AssociatedImage.Decoded()` accessor — depends on decoder layer
  integration; v0.24+.
- v1.0 tag — happens when the full strategic sketch is implemented.

Non-goals:

- Backward compatibility shims for the old `Tiler` interface. The only
  consumer is wsitools and it is migrated in lockstep. No deprecation
  window.
- Behavior changes. Every existing format reader keeps its byte-for-byte
  output exactly; only the surface shape changes.

## 3. Architecture overview

```
opentile-go/
    slide.go                         *Slide struct, OpenFile, Open, Close,
                                     all public methods (delegate to r)
    format.go, levels.go, ...        existing value-types (Format, Level,
                                     Metadata, AssociatedImage, TIFFTag,
                                     Compression) preserved unchanged
    options.go                       Option type for Open(...)

    internal/format/
        reader.go                    `Reader` interface; constructors
                                     register via init() into the
                                     Registry; OpenFile probes registered
                                     formats and returns the first match
        registry.go                  format-detection + registration
                                     plumbing (likely already exists;
                                     formalize if not)

    formats/svs/                     constructor returns format.Reader
                                     instead of opentile.Tiler
    formats/philipstiff/             same
    formats/ometiff/                 same
    formats/biftiff/                 same
    formats/ifetiff/                 same
    formats/generictiff/             same
    formats/cogwsi/                  same
    formats/szi/                     same
    formats/all/                     unchanged (blank-imports each)

    DELETED:
        tiler.go                     Tiler interface, OpenTiler — gone
        anywhere else publicly exporting Tiler-shaped types
```

`*Slide` is a thin forwarder over `format.Reader`:

```go
type Slide struct {
    r format.Reader
}

func (s *Slide) Format() Format                              { return s.r.Format() }
func (s *Slide) Metadata() Metadata                          { return s.r.Metadata() }
func (s *Slide) Levels() []Level                             { return s.r.Levels() }
func (s *Slide) Associated() []AssociatedImage               { return s.r.Associated() }
func (s *Slide) TIFFTags() []TIFFTag                         { return s.r.TIFFTags() }
func (s *Slide) RawTile(level, tx, ty int) ([]byte, error)   { return s.r.RawTile(level, tx, ty) }
func (s *Slide) RawTileInto(level, tx, ty int, dst []byte) (int, error) {
    return s.r.RawTileInto(level, tx, ty, dst)
}
func (s *Slide) Close() error                                { return s.r.Close() }
```

The format-detection flow:

```go
func OpenFile(path string) (*Slide, error) {
    f, err := os.Open(path)
    if err != nil { return nil, err }
    // Open delegates; OpenFile is the convenience entry.
    fi, err := f.Stat()
    if err != nil { f.Close(); return nil, err }
    return Open(f, fi.Size())
}

func Open(r io.ReaderAt, size int64, opts ...Option) (*Slide, error) {
    cfg := defaultConfig()
    for _, o := range opts { o(&cfg) }

    reader, err := format.OpenAny(r, size, cfg)  // probes registered formats
    if err != nil { return nil, err }
    return &Slide{r: reader}, nil
}
```

`format.OpenAny` is the existing format-probing logic, moved or
re-shaped from wherever `OpenTiler` currently does it.

## 3.1 Amendment (post-survey): full public surface

Pre-plan survey of the current API revealed several methods the
initial sketch omitted. v0.23 ships ALL of the surface below (per
"Full redesign per strategic doc" decision):

```go
// Construction
func OpenFile(path string, opts ...Option) (*Slide, error)
func Open(r io.ReaderAt, size int64, opts ...Option) (*Slide, error)
func (s *Slide) Close() error

// Identity + metadata (inspection-only; no I/O)
func (s *Slide) Format() Format
func (s *Slide) Metadata() Metadata
func (s *Slide) ICCProfile() []byte
func (s *Slide) Associated() []AssociatedImage
func (s *Slide) TIFFTags() []TIFFTag

// Multi-image accessors. OME-TIFF can carry multiple pyramid groups.
// Single-image formats return a one-element slice.
func (s *Slide) Images() []Image
func (s *Slide) Levels() []Level                              // shortcut for Images()[0].Levels
func (s *Slide) Level(i int) (Level, error)                   // shortcut for Images()[0].Level(i)

// Raw tile access. Takes a level INDEX rather than a Level value.
func (s *Slide) RawTile(level, tx, ty int) ([]byte, error)
func (s *Slide) RawTileInto(level, tx, ty int, dst []byte) (n int, err error)
func (s *Slide) ImageRawTile(image, level, tx, ty int) ([]byte, error)
func (s *Slide) ImageRawTileInto(image, level, tx, ty int, dst []byte) (n int, err error)

// Page-cache pre-warm. Same contract as current Tiler.WarmLevel.
func (s *Slide) WarmLevel(i int) error
```

### Level and Image become value-types

`Level` and `Image` are interfaces in the current API. v0.23 converts
them to value-type structs (inspection fields only; tile reads on
`*Slide`):

```go
// Image identifies one pyramid group within a slide. Multi-image
// OME-TIFF carries several; single-image formats carry one.
type Image struct {
    // Name + Index preserve identity. The Levels slice carries the
    // pyramid for this image.
    Name   string
    Index  int
    Levels []Level
}

// Level is value-type pyramid-level metadata. All fields are
// inspection-only; tile reads use *Slide.RawTile.
type Level struct {
    Index               int            // 0-based level index within the parent Image
    Width, Height       int            // pixel dimensions of this level
    TileWidth, TileHeight int          // tile dimensions
    Compression         Compression
    Downsample          float64        // canonical downsample factor from L0
    ImageDescription    string         // for SVS-style descriptive metadata
    // Other inspection-only fields preserved verbatim from the
    // current Level interface (anything callers currently read).
}
```

The implementation plan's Phase-0 survey enumerates every current
Level interface method and maps each to either (a) a struct field,
(b) a `*Slide` method, or (c) deletion if unused.

## 4. The `format.Reader` interface

Lives at `internal/format/reader.go`. Exported within the module so
format packages can reference its type for return values.

```go
package format

import (
    "io"

    opentile "github.com/wsilabs/opentile-go"
)

// Reader is the interface every format implementation provides. The
// opentile package's Slide type wraps a Reader and delegates all
// method calls. This interface is internal to opentile-go; external
// callers must use *opentile.Slide.
type Reader interface {
    Format() opentile.Format
    Metadata() opentile.Metadata
    Levels() []opentile.Level
    Associated() []opentile.AssociatedImage
    TIFFTags() []opentile.TIFFTag
    RawTile(level, tx, ty int) ([]byte, error)
    RawTileInto(level, tx, ty int, dst []byte) (n int, err error)
    Close() error
}

// Opener probes an io.ReaderAt to determine if the format matches
// and, if so, constructs a Reader. Registered by format packages in
// their init() functions.
type Opener func(r io.ReaderAt, size int64, cfg Config) (Reader, error)

// Match probes whether this format applies; returns nil iff yes.
type Match func(r io.ReaderAt, size int64) error

// Config is whatever options.go passes down (BigTIFF tolerance,
// strict-mode toggles, etc. — preserve the existing Option type's
// payload shape).
type Config struct { /* ... existing fields ... */ }

// Register adds a format to the global registry. Called from each
// format package's init().
func Register(name string, match Match, opener Opener)

// OpenAny probes registered formats in registration order; the first
// that matches is opened. Returns ErrUnknownFormat if none match.
func OpenAny(r io.ReaderAt, size int64, cfg Config) (Reader, error)

// ErrUnknownFormat is returned by OpenAny when no registered format
// claims the input.
var ErrUnknownFormat = errors.New("opentile: unknown format")
```

Each format package registers itself:

```go
// formats/svs/svs.go
package svs

import (
    "github.com/wsilabs/opentile-go/internal/format"
)

func init() {
    format.Register("svs", matchSVS, openSVS)
}

func matchSVS(r io.ReaderAt, size int64) error { /* ... */ }
func openSVS(r io.ReaderAt, size int64, cfg format.Config) (format.Reader, error) { /* ... */ }
```

The existing `formats/all` package keeps blank-importing every format;
no consumer-facing change.

## 5. Migration mechanics

### Within opentile-go

Approach the cut as a tight refactor:

1. Add `internal/format/reader.go` with the `Reader` interface +
   `Register` + `OpenAny`.
2. For each format package, convert its constructor (currently named
   per the existing convention — typically `Open`, `Detect`, etc.) to
   return `format.Reader` and call `format.Register(...)` in `init()`.
   Most of the underlying struct + methods stays the same; only the
   return type changes.
3. Rewrite `opentile.OpenFile` / `opentile.Open` to use
   `format.OpenAny` and wrap in `*Slide`.
4. Delete the public `Tiler` interface and `OpenTiler` constructor.
5. Verify the existing TestSlideParity / TestParityOracle integration
   tests still pass on all sample slides.

### Within wsitools

1. Bump `github.com/wsilabs/opentile-go` to v0.23.0.
2. Every `opentile.OpenTiler(...)` call becomes `opentile.OpenFile(...)`;
   every `tiler.RawTile(...)` stays exactly the same (method signature
   preserved on `*Slide`).
3. Every variable typed `opentile.Tiler` becomes `*opentile.Slide`.
4. Run full test suite (including byte-stability) — must pass with no
   semantic changes.

### Release sequencing

1. opentile-go: branch `feat/v23-slide-redesign`, ship v0.23.0.
2. wsitools: branch `feat/v11-slide-migration`, bump dep to v0.23.0,
   migrate call sites, ship v0.11.0.

Order matters: opentile-go must tag first so wsitools can `go get
@v0.23.0`.

## 6. Release notes

The v0.23.0 CHANGELOG entry MUST document the API break thoroughly.
This is a hard requirement, not a nice-to-have — the change is
breaking-by-design and the release notes are the primary migration
guide.

Required content for `CHANGELOG.md`:

```markdown
## [0.23.0] — TBD

**BREAKING:** Replaced the public `Tiler` interface with a `*Slide` struct.

### Removed (BREAKING)

- `opentile.Tiler` interface — gone entirely; no deprecation shim.
- `opentile.OpenTiler(path string) (Tiler, error)` — use
  `opentile.OpenFile(path string) (*Slide, error)`.
- (List every other public name removed; check the diff and enumerate.)

### Added

- `opentile.Slide` struct — new canonical handle for an open slide.
- `opentile.OpenFile(path) (*Slide, error)` — open by path.
- `opentile.Open(r io.ReaderAt, size int64, opts ...Option) (*Slide, error)`
  — open from any ReaderAt; identical option set to old `OpenTiler`.
- `(*Slide).Close() error`
- `(*Slide).Format() Format`
- `(*Slide).Metadata() Metadata`
- `(*Slide).Levels() []Level`
- `(*Slide).Associated() []AssociatedImage`
- `(*Slide).TIFFTags() []TIFFTag`
- `(*Slide).RawTile(level, tx, ty int) ([]byte, error)` —
  identical signature to the old `Tiler.RawTile`.
- `(*Slide).RawTileInto(level, tx, ty int, dst []byte) (int, error)` —
  identical signature to the old `Tiler.RawTileInto`.

### Migration guide

The shape of the API is unchanged — method signatures on `*Slide`
mirror the previous `Tiler` interface exactly. Migrating a consumer
is a mechanical rename:

| Before                                  | After                                |
| --------------------------------------- | ------------------------------------ |
| `opentile.Tiler`                        | `*opentile.Slide`                    |
| `opentile.OpenTiler(path)`              | `opentile.OpenFile(path)`            |
| `t.RawTile(level, tx, ty)`              | unchanged                            |
| `t.Levels()`, `t.Metadata()`, etc.      | unchanged                            |
| `t.Close()`                             | unchanged                            |

For each consumer, the migration is:
1. Bump opentile-go to v0.23.0.
2. Search-and-replace `opentile.OpenTiler(` → `opentile.OpenFile(`.
3. Search-and-replace declared types `opentile.Tiler` →
   `*opentile.Slide`.
4. Compile; fix any straggler references.

### Why this change

The old `Tiler` interface forced every format implementer to grow in
lockstep with the public API. Adding decoded-tile methods, region
reads, or a strip iterator would require every format to implement
them or break the interface contract. Collapsing to `*Slide` with a
format reader as an unexported interface lets future methods land on
`*Slide` without touching format implementations.

This is the first installment of the v1.0 redesign sketched in
`docs/strategic-direction.md`. v0.24+ will add decoded-tile access;
v0.25+ adds region reads; the strip iterator with parallel decode +
cache + lookahead is the v1.0 milestone.
```

The CHANGELOG section is referenced by the v0.23.0 GH release notes
verbatim. The migration table is the primary deliverable for
end-users.

## 7. Testing strategy

### Existing test infrastructure preserved

- All `TestSlideParity`, `TestParityOracle`, `TestFooBitExact` integration
  tests continue to pass. They get mechanical rename
  (`opentile.OpenTiler` → `opentile.OpenFile`) but the slides they open
  produce identical output bytes (this is a surface refactor, not a
  semantic change).
- Per-format unit tests in each `formats/<name>/` package continue to
  pass with their constructors returning `format.Reader` instead of
  `opentile.Tiler`.

### New tests

- `slide_test.go` in the `opentile` package, covering:
  - `OpenFile` succeeds for one sample of each registered format.
  - `OpenFile("/nonexistent")` returns a file-system error.
  - `Open(emptyBuf, 0)` returns `format.ErrUnknownFormat` wrapped.
  - `*Slide.Close()` is idempotent (no panic on second call).
  - `*Slide` method calls delegate correctly (covered transitively by
    the parity tests; no need for explicit mocking).

### Format registry tests

- `internal/format/registry_test.go`:
  - `Register` adds; `OpenAny` finds.
  - First-matching-Match wins (registration order).
  - `ErrUnknownFormat` returned when no Match succeeds.

## 8. Backward compatibility

None. This is a clean break.

- The only consumer is wsitools.
- wsitools migrates in lockstep (v0.11.0 follows opentile-go v0.23.0).
- No deprecation shim.

Any external code (none known to exist) that imported the public
`Tiler` interface will not compile against v0.23.0. The migration is
mechanical (per the table above) and the CHANGELOG documents it
exhaustively.

## 10. Out-of-scope items (forward-looking)

internalize the format-reader contract. The strategic doc's full
sketch is built up in subsequent releases:

starting point.
