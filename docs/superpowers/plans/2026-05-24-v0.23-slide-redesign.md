# opentile-go v0.23 — *Slide Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace opentile-go's public `Tiler` interface with a `*Slide` struct that wraps a new unexported `format.Reader` interface. Level + Image stay interfaces in v0.23 (their value-type conversion is deferred to v0.24). wsitools migrates in lockstep as v0.11.0.

**Architecture:** New `internal/format` package owns the `Reader` interface (≈ current `Tiler`, internalized) plus format registration. Format-package constructors return `format.Reader` instead of `opentile.Tiler`. The public `*Slide` struct wraps a `format.Reader` and forwards every method call. `Tiler`, `OpenTiler`, and the `FormatFactory` machinery are deleted entirely (no deprecation shim).

**Tech Stack:** Go 1.26+, pure-Go (no cgo changes). Existing packages: `formats/{svs,ndpi,philipstiff,ometiff,bif,ife,generictiff,leicascn,szi,cogwsi}`, top-level `opentile`, no decoder dep added.

- Existing format-package examples: `formats/svs/svs.go`, `formats/ometiff/ometiff.go` (representative shapes)

```go
package format

import (
	"errors"
	"io"

	opentile "github.com/wsilabs/opentile-go"
)

// Reader is the contract every format implementation provides.
// Shape mirrors the pre-v0.23 public Tiler interface exactly, just
// internalized so the public surface (*opentile.Slide) can evolve
// without forcing every format to grow in lockstep.
type Reader interface {
	Format() opentile.Format
	Images() []opentile.Image
	Levels() []opentile.Level
	Level(i int) (opentile.Level, error)
	Associated() []opentile.AssociatedImage
	Metadata() opentile.Metadata
	ICCProfile() []byte
	WarmLevel(i int) error
	Close() error
}

// Config is passed from opentile.Open's option-config down into each
// format's Opener. Fields preserved verbatim from the existing
// (internal) Config that opentile.Open passes to FormatFactory.Open.
// See opentile/options.go for the field list.
type Config struct {
	// Populated by opentile's option-config translation. The exact
	// fields depend on what FormatFactory.Open currently accepts;
	// preserve them all.
}

// Opener constructs a Reader from a parsed input. r is the raw bytes;
// cfg is the option-derived config. Returns a non-nil Reader on success.
type Opener func(r io.ReaderAt, size int64, cfg *Config) (Reader, error)

// Match returns nil if the format applies to this input, or an error
// describing why it doesn't (the error is informational; only nil/non-nil
// determines dispatch).
type Match func(r io.ReaderAt, size int64) error

// ErrUnknownFormat is returned by OpenAny when no registered format
// claims the input.
var ErrUnknownFormat = errors.New("opentile: unknown format")
```

Create `internal/format/registry.go`:

```go
package format

import (
	"io"
	"sync"
)

type entry struct {
	name   string
	match  Match
	opener Opener
}

var (
	regMu sync.RWMutex
	reg   []entry
)

// Register adds a format to the global registry. Called from each
// format package's init() function. Registration order matters:
// OpenAny dispatches in registration order; first Match wins.
func Register(name string, match Match, opener Opener) {
	regMu.Lock()
	defer regMu.Unlock()
	reg = append(reg, entry{name: name, match: match, opener: opener})
}

// OpenAny probes registered formats in registration order. The first
// whose Match returns nil wins; its Opener is invoked. Returns
// ErrUnknownFormat if no format matches.
func OpenAny(r io.ReaderAt, size int64, cfg *Config) (Reader, error) {
	regMu.RLock()
	defer regMu.RUnlock()
	if cfg == nil {
		cfg = &Config{}
	}
	for _, e := range reg {
		if err := e.match(r, size); err == nil {
			return e.opener(r, size, cfg)
		}
	}
	return nil, ErrUnknownFormat
}

// snapshot + restore + reset are TEST-ONLY helpers exported within
// the package (not via package-level visibility) for registry tests
// that need to clear or restore the registered set. The internal_test
// pattern allows white-box testing.
func snapshot() []entry {
	regMu.RLock()
	defer regMu.RUnlock()
	return append([]entry(nil), reg...)
}

func restore(snapshot []entry) {
	regMu.Lock()
	defer regMu.Unlock()
	reg = snapshot
}

func reset() {
	regMu.Lock()
	defer regMu.Unlock()
	reg = nil
}
```

Create `slide.go`:

```go
package opentile

import (
	"fmt"
	"io"
	"os"

	"github.com/wsilabs/opentile-go/internal/format"
)

// Slide is the canonical handle for an open whole-slide image.
// Constructed via OpenFile (path) or Open (io.ReaderAt). Replaces the
// pre-v0.23 Tiler interface.
//
// Concurrency contract: see the historical Tiler doc on tiler.go for
// the per-method threading promises. Slide preserves them verbatim;
// Slide is a thin forwarder over the format-specific reader.
type Slide struct {
	r format.Reader
}

// OpenFile opens path for reading. The returned Slide owns the
// underlying file handle (or memory map); Close releases it. Default
// backing is BackingMmap; use WithBacking(BackingPread) to opt out.
//
// Failure modes match the pre-v0.23 OpenFile (errors wrapped with
// ErrMmapUnavailable, ErrInvalidTIFF, ErrUnsupportedFormat).
func OpenFile(path string, opts ...Option) (*Slide, error) {
	cfg := newConfig(opts)
	switch cfg.backing {
	case BackingMmap:
		return openFileMmap(path, opts)
	case BackingPread:
		return openFilePread(path, opts)
	default:
		return nil, fmt.Errorf("opentile: unknown backing %d", cfg.backing)
	}
}

// Open parses r as a slide of any registered format. size is the
// total byte count of r.
//
// Dispatch matches the pre-v0.23 behavior: each registered format's
// Match is invoked in registration order; the first to return nil
// wins. ErrUnknownFormat is returned if none match.
func Open(r io.ReaderAt, size int64, opts ...Option) (*Slide, error) {
	cfg := newConfig(opts)
	fcfg := configToFormatConfig(cfg)
	rdr, err := format.OpenAny(r, size, fcfg)
	if err != nil {
		return nil, err
	}
	return &Slide{r: rdr}, nil
}

// Close releases resources held by the slide. After Close, all other
// methods return ErrClosed (or panic for unguarded fast paths;
// preserve current Tiler.Close semantics).
func (s *Slide) Close() error { return s.r.Close() }

// Format returns the canonical format identifier.
func (s *Slide) Format() Format { return s.r.Format() }

// Images returns the main pyramids carried by this file. Always
// returns at least one Image; multi-image OME-TIFF exposes multiple.
// Index 0 is the legacy Levels() / Level(i) shortcut target.
func (s *Slide) Images() []Image { return s.r.Images() }

// Levels is a shortcut for s.Images()[0].Levels().
```
